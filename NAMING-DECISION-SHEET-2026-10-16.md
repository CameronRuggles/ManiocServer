## DECIDED — 2026-10-17 (Cameron)

- **The OS is "Manioc Server".**
- **The marketplace software is "Polyculture Markets"** (working abbreviation: PCM).

Both names come off the James C. Scott shelf:

- **Manioc Server** — manioc (cassava) is Scott's escape crop: it grows underground, invisible to the surveyor, cannot be assessed, taxed, or confiscated like standing grain, and is dug on the eater's schedule, not the tax collector's. A home server whose site sits beneath the visible web — un-surveyable, served on the owner's terms — is that crop's posture as a machine. (*Against the Grain*; *The Art of Not Being Governed*.)
- **Polyculture Markets** — the swidden plot against the plantation. Polyculture is diverse, interplanted, resilient, and illegible from above; monoculture is the platform model — uniform, legible, fragile. The software spawns many independent markets rather than running one, hence the plural; the word is also native vocabulary in the permaculture/homestead audience. (*Seeing Like a State*; *The Art of Not Being Governed*.)

## Pair A — Polistes (OS) + Annularis (marketplace) — SUPERSEDED 2026-10-17
- Taxonomy is the architecture: genus contains species the way the OS contains the marketplace.
- *Polistes* likely from Greek *polistes*, "founder of a city" — the OS founds a city on a home box.
- *annularis* = "ringed" — wasp marking, and "rings" to a Monero audience. *P. annularis* nests are typically built by associations of cooperating foundresses (avg ~5, up to 22) — matches the chosen first-follower / co-foundress donations message.
- Annularis is Cameron's own earlier project (open-source PHP Monero marketplace, "not production ready," donations-funded, linked to BitWasp's page) — reviving it is a return story, and that history must be framed deliberately.
- Spelling variant still open: **Polistes** (true genus spelling, used in the unbiased prompt Cameron had prepared for two other AIs) vs **Polstice** (Cameron's invented spelling — more ownable, but sounds like Mersive's "Solstice" product in conversation).
- Costs: hardest mouth test of the live options — non-technical users (the OS's target) cannot reliably pronounce/spell either name on first hearing. Story is inert until explained, then excellent.

## Option C — Rootcllr (OS), marketplace partner unresolved — SUPERSEDED 2026-10-17
- Cameron's layered case for Rootcellar: (1) a root cellar is literally where you keep onions — the onion-service pun without the word "Onion" or Tor trademark risk; (2) "root" is the Linux root user / root filesystem, and the engine runs rootful; (3) root cellars keep stores through winter.
- Compressed spelling **Rootcllr** (not Rtcllr — keeping "root" spelled out preserves the Linux reading and avoids the RTC collision) solves the domain problem: rootcllr.org free today.
- Costs: hear-it-type-it leak — someone hears "Rootcellar," types the natural spelling, lands on someone else's (registered) sites. Logo would need to teach the spelling.
- Pairing problem: its natural partner Handcart is taken in .com and .org, and compressing Handcart doesn't work. Rootcllr would need a different marketplace partner (Annularis is the available candidate mentioned last night) or stand alone.

## Appendix — second unbiased prompt, ready if Cameron wants Rootcllr judged the same way
Same neutral software description as the Polistes/Annularis prompt prepared last night, with only the name under test changed. It deliberately explains nothing about onions, Linux "root," cellars, or the taken full-spelling domains.

```text
I'm developing an open-source software project, and I want your honest opinion on the name I'm considering for it.

PROJECT — an operating system
A Debian-based operating system that turns an ordinary home desktop computer into a web server reachable over the Tor network as an onion service. It is aimed at non-technical users, with a click-through installer rather than command-line setup. The disk is fully encrypted and a passphrase must be entered at every boot. The website runs in an isolated container with no direct network access; a separate Tor gateway container is the only part allowed online and it holds the site's onion identity key, so a compromised website cannot learn the home's IP address or steal the site's identity. It includes built-in tools for publishing simple pages and a journal, and owners can also install other web software such as forums and blogs, which run in the same isolated environment. Updates are signed, delivered over Tor, and roll back automatically if they fail a health check. It is free and open source, funded by donations, with no company, no accounts, and no fees.

The name I'm considering is: "Rootcllr"

Is this a good name for this software? Please give me an honest assessment, including first impressions, strengths, weaknesses, how it sounds and how easy it is to pronounce, spell, remember and search for, whether it fits what the software does and who it's for, and any risks, confusion or negative associations you see. Don't be polite about it if you think it's bad.
```
